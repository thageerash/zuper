6. Fix list, in order

  1. Read the job from the query (address, customer, crew) before picking an answer. Build gutter / decking / ground answers per job instead of one fixed job each.
  2. When no job is named and several match, answer with a "Which job?" choice instead of guessing.
  3. Fix keyword order: "ground" and "waiver" win over "before". Add intents for retake/blur and extra work.
  4. Point each answer's main button at the open item's correct step; show the decision if it's already resolved.
  5. Make sources open what they name (voice note, email) instead of a photo or toast.
  6. Use one search rule for ⌘K, Dispute step 1 and Photos so the same words give the same photos.
  7. Align data: sync times (answer vs Crews panel), Ravi's Pine Ave job, and which job W7 / the insurer case is.
  8. Port W1 (extra work) and W6b (ask about this job) into Office Inbox v2. Renumber the W-screens so each number is used once.
