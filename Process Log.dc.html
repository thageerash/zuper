Summary

How AI was used on this project

Claude was the main tool for research, flows, audits and building the mobile and web prototypes. Mobbin was used for layout references, and a second AI tool wrote the master brief and several outside reviews, which were pasted back in and audited before anything was applied. Every decision was checked against the problem statement: capture, custody and proof.

03FlowsCrew and office flows sharing one set of photo states, then cut back to one simple path per person.

05Office webSean and Priya on one dashboard with a shared entry point, then each section refined against Mobbin.
